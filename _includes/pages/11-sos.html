결과 : 연결을 복구해 상품/주문 흐름을 실행했습니다. 이후 DaySync에서는 API 명세, ERD, 시퀀스를 먼저 작성해
요청/응답과 데이터 처리 위치를 정리하고 화면과 서버의 책임을 나눈 뒤 구현하도록 개발 순서를 바꿨습니다.
