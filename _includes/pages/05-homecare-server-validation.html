상태 전환

상담 화면에 남아 있는 지난 카드를 뒤늦게 눌러도 현재 상담 내용이 바뀌지 않도록, 답변이 들어올 때마다
본인의 제품인지, 지금 단계의 카드가 맞는지, 그사이 상담 내용이 바뀌지 않았는지를 확인했습니다.
또한 오래된 카드와 중복 제출은 409로 거부하고 정상 제출은 기존과 같은 최종 상태로 종료했습니다.

보증/비용 안내

입력 경로 없이 null인 구입 증빙/가정용 사용 값이 만료일 계산 조건이라 UNKNOWN(‘추가 확인 필요’)을 반환하였고
만료일은 구매일과 정책 기간으로 계산하도록 했고 두 값은 실제 무상 적용을 판정할 때만 사용하도록 분리/적용했습니다.
실제 무상 여부는 점검 때 확정한다고 안내하며 금액이 없던 비용 항목 대신 참고 수리비와 공식 접수 경로를 제공했습니다.
