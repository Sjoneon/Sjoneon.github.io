01. Spring AI로 제품별 제조사 근거 검색

다른 모델의 조치를 안내하면 잘못된 점검으로 이어질 수 있어 검색 전 제품의 적용 조건을 확인해야 했습니다.
Spring AI 검색에 품목/모델 조건을 적용하고 검색용 텍스트와 표시 원문을 분리해 제품별 근거를 반환하여
사용자에게 보다 정확한 정보를 제공했습니다.

  1. FILTER적용 조건 확인

    품목/모델
    제외 조건 검증

  2. RETRIEVE후보 검색

    오류코드/증상 어휘
    임베딩 유사도 결합

  3. FALLBACK장애 대응

    의미 검색 장애 시
    어휘 검색으로 전환

  4. RESPOND근거 부족 처리

    추가 확인 또는
    자료 부족 안내
